# spider-trait-database-frontend

## Project setup

```sh
npm install
```

### Compiles and hot-reloads for development

```sh
npm run serve
```

The Vite development server runs on its default port, `5173`.

### Compiles and minifies for production

```sh
npm run build
```

### Lints and fixes files

```sh
npm run lint
```

### Preview production build locally

```sh
npm run preview
```
